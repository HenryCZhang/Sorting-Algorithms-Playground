### 项目背景：
Sorting Algorithms Playground 是一个面向算法学习者的教育类互动网站，通过游戏化的方式帮助用户理解常见排序算法的工作原理与实现逻辑。平台提供可视化演示、交互式练习和进度跟踪功能，提升学习趣味性与理解效率。

### 关键技术栈：
- 前端 ：React, jQuery, HTML, CSS, JavaScript
- 后端 ：Node.js（基于上下文推测）
- 数据库 ：MySQL
- 部署与认证 ：Firebase

### 核心职责与成果：
- 与团队协作完成前端页面设计与开发，使用 React 构建模块化组件，实现响应式布局与动态交互体验。
- 参与 RESTful API 接口开发，确保前后端数据高效通信，支持用户行为记录与算法状态同步。
- 设计并搭建后端数据库模型，使用 MySQL 存储用户信息、学习进度与交互数据，并优化查询逻辑以提高系统性能。
- 使用 Firebase 完成网站部署与用户身份验证管理，保障系统的安全性与可用性。

### 应用价值：
- 提供直观的排序算法可视化演示，降低算法学习门槛，提升学习效率。
- 游戏化机制增强用户参与感与持续学习动力，适用于初学者与编程爱好者。
- 支持个性化学习路径与进度追踪，为用户提供定制化的学习体验。

## The Algorithms

➡️  We started with the MergeSort as the default algorithm. The system can be designed to allow other algorithms to be added later. 

➡️  Currently we have 
* Merge Sort
* Bubble Sort
